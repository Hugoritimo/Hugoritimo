Desenvolvo sistemas internos que substituem planilhas e processos manuais por fluxos digitais confiáveis, com foco em controle financeiro, compras e operação de engenharia. Atuo do banco de dados à interface: modelagem em PostgreSQL, APIs e aplicações web e mobile em TypeScript. Curso Engenharia da Computação (BICT) na UFMA.
